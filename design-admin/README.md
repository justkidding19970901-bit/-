# Designer Studio（MonnaCase 設計部）

單一設計師的每月 KPI、庶務控管與職涯成長工具。純前端（localStorage），含主管／設計師分權，並把效率診斷報告的建議內建成天天可用的工具。

> 完整效率診斷見 [`docs/設計師效率診斷報告.md`](docs/設計師效率診斷報告.md)。

## 功能
- **統合儀表**：手機殼 KPI（x/4）、商品圖/電商圖、抽成金額、夜市工時 vs KPI 取捨、產能緩衝庫。
- **產出清單**：手機殼／商品圖／電商圖／抽成，狀態追蹤（備稿中/進行中/待確認/已完成），按月分流。
- **夜市排班**：當月週末排班與出勤，計入損失工時估算。
- **詳情頁檢查清單**：上架前逐項勾選（報告對策 C）。
- **上架圖規格**：16 Pro / 17 Pro 固定尺寸對照（報告對策 B）。
- **KPI 目標設定**（主管）：逐月調整目標，讓 KPI 與夜市工時對齊。
- **成員管理**（主管）：新增可登入成員。

## 啟動
```bash
npm install
npm run dev      # http://localhost:3001
npm run build    # 型別與建置檢查
```

## 登入
種子資料含「主管」與「設計師」兩個帳號。
- 主管登入需通行碼，預設 `admin`（可於 `lib/storage.ts` 的 `MANAGER_PASSCODE` 修改）。
- 設計師直接選擇即可登入。

## 注意
- 資料存於瀏覽器 localStorage，僅單機、不跨裝置同步；清除瀏覽器資料會遺失。
- 角色分權屬 UI 層級，非真正資安隔離。未來要多人共享/真正權限，改 `lib/storage.ts` 這層資料存取為雲端後端即可。
